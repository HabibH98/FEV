# Retro

## Wat heb ik gedaan?

Ik heb mijn React-project opgezet met Vite en JavaScript.
Daarna heb ik onderzocht hoe de bestanden van een React-project werken.

Ik heb de standaard Vite-pagina vervangen door mijn eigen inhoud en mijn
eerste React-component gemaakt voor de navigatie van de website.

## Wat ging goed?

Het aanmaken en starten van het React-project ging goed nadat ik begreep
hoe Vite werkt.

Het maken van mijn eerste component ging ook goed. Ik begrijp nu beter
waarom React een website in verschillende componenten verdeelt.

## Wat ging minder goed?

In het begin wist ik nog niet goed hoe Vite werkte en waarom ik het nodig had.
Ook stopte de lokale server een keer, waardoor localhost niet meer werkte.

Bij het maken van `Navbar.jsx` had ik een kleine typefout in de code.
Hierdoor heb ik geleerd dat kleine fouten ervoor kunnen zorgen dat code
niet werkt.

## Wat heb ik geleerd?

Ik heb geleerd hoe ik:

- een React-project aanmaak;
- Vite gebruik;
- de development server start;
- JSX schrijf;
- een React-component maak;
- componenten importeer en exporteer.
