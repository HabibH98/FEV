## Projectgegevens

### Naam van het project
Restaurant Reserveringswebsite

### Beschrijving van het project
Voor dit project maak ik een website voor een restaurant. Bezoekers kunnen
informatie over het restaurant en de menukaart bekijken en online een tafel
reserveren.

De website wordt gemaakt met React, JavaScript/JSX en CSS.

### Waarom wil ik dit project maken?
Ik heb voor dit project gekozen omdat ik wil leren werken met React.
Daarnaast wil ik leren hoe ik een responsive website
kan maken.

### Randvoorwaarden

Bij het ontwikkelen van de website houd ik rekening met:

- **AVG:** persoonsgegevens zoals naam, e-mailadres en telefoonnummer moeten
  veilig en zorgvuldig worden behandeld.
- **Copyright:** ik gebruik geen afbeeldingen of andere content zonder
  toestemming of geschikte licentie.
- **Licenties:** ik controleer de licenties van libraries en andere middelen
  die ik gebruik.
- **Wettelijke impact:** de website moet op een correcte manier omgaan met
  persoonsgegevens van gebruikers.

  # Leerdoelen

1. **Werken met React**
   Ik wil leren hoe ik met React een website kan bouwen en hoe ik verschillende componenten kan maken en gebruiken.

2. **JavaScript en JSX verbeteren**
   Ik wil mijn kennis van JavaScript verbeteren en leren hoe ik JSX binnen React kan gebruiken.

3. **Responsive website maken**
   Ik wil leren hoe ik met CSS een website kan maken die goed werkt op mobiel, tablet en desktop.

4. **Formulieren maken en controleren**
   Ik wil leren hoe ik een reserveringsformulier kan maken waarin gebruikers gegevens kunnen invullen en hoe ik deze invoer kan controleren.

5. **Website testen**
   Ik wil leren hoe ik mijn website goed kan testen op verschillende apparaten en browsers en hoe ik feedback van gebruikers kan gebruiken om de website te verbeteren.
- **Maatschappelijke impact:** de website moet duidelijk en gemakkelijk te
  gebruiken zijn voor verschillende gebruikers en apparaten.
