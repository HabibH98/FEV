# Leerdoelen

1. **Werken met React**
   Ik wil leren hoe ik met React een website kan bouwen en hoe ik verschillende componenten kan maken en gebruiken.

2. **JavaScript en JSX verbeteren**
   Ik wil mijn kennis van JavaScript verbeteren en leren hoe ik JSX binnen React kan gebruiken.

3. **Responsive website maken**
   Ik wil leren hoe ik met CSS een website kan maken die goed werkt op mobiel, tablet en desktop.

4. **Formulieren maken en controleren**
   Ik wil leren hoe ik een reserveringsformulier kan maken waarin gebruikers gegevens kunnen invullen en hoe ik deze invoer kan controleren.

5. **Website testen**
   Ik wil leren hoe ik mijn website goed kan testen op verschillende apparaten en browsers en hoe ik feedback van gebruikers kan gebruiken om de website te verbeteren.
