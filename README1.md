# Restaurant Reserveringswebsite

## Project

Voor Frontend Verdieping maak ik een reserveringswebsite voor een restaurant.
De website wordt gebouwd met React en JavaScript.

Het doel is om uiteindelijk een website te maken waarop bezoekers informatie
over het restaurant kunnen bekijken en een tafel kunnen reserveren.

## Technieken

Voor dit project gebruik ik:

- React
- JavaScript / JSX
- CSS
- Vite
- ESLint

## Wat heb ik tot nu toe gemaakt?

Ik heb eerst met Vite een nieuw React-project aangemaakt.

Daarna heb ik bekeken hoe de standaard React-structuur werkt, zoals:

- `main.jsx`
- `App.jsx`
- `App.css`
- `index.css`
- `components`

Ik heb de standaard inhoud van Vite uit `App.jsx` verwijderd en mijn eigen
inhoud toegevoegd.

Ook heb ik mijn eerste eigen React-component gemaakt: `Navbar.jsx`.

De Navbar bevat op dit moment:

- Home
- Menu
- Over ons
- Reserveren
- Contact

De Navbar wordt vanuit `App.jsx` geïmporteerd en weergegeven.
