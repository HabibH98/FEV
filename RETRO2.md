# Retrospective 2

## Wat heb ik gedaan?

Deze periode ben ik verder gegaan met mijn restaurant-reserveringswebsite.

Ik heb de website verder opgebouwd met React. Ik heb verschillende pagina's
gemaakt en React Router toegevoegd zodat ik tussen de pagina's kan navigeren.

Ik heb de volgende pagina's gemaakt:

- Home
- Menu
- Over ons
- Reserveren
- Contact

Ook heb ik de navigatiebalk en de homepage verder gemaakt en gestyled met CSS.

## Wat ging goed?

Het maken van nieuwe React-componenten ging beter dan de vorige keer.
Ik begrijp nu beter waarom we verschillende onderdelen in aparte bestanden
zetten.

Het installeren en gebruiken van React Router ging ook goed. De navigatie
werkt en ik kan tussen de verschillende pagina's wisselen.

Ook is het gelukt om de navigatie responsive te maken voor kleinere schermen.

## Wat ging minder goed?

React Router was in het begin nieuw voor mij. Ik moest eerst begrijpen
waarom we BrowserRouter, Routes, Route en Link nodig hebben.

Ook moest ik wennen aan het verschil tussen gewone HTML-links en Link
van React Router.

## Wat heb ik geleerd?

Deze periode heb ik geleerd:

- hoe ik meerdere pagina-componenten maak;
- hoe ik React Router installeer;
- hoe BrowserRouter werkt;
- hoe Routes en Route werken;
- hoe ik Link gebruik om te navigeren;
- hoe ik CSS gebruik om mijn navigatie te stylen;
- hoe ik met een media query de website responsive maak;
- hoe ik een hero-gedeelte voor de homepage maak.

## Wat wil ik verbeteren?

Ik wil de volgende keer meer JavaScript gebruiken in mijn project.
Tot nu toe heb ik vooral gewerkt met React-componenten, JSX, routing en CSS.

Ik wil beter begrijpen hoe ik gegevens in JavaScript kan opslaan en deze
dynamisch kan tonen met React.
