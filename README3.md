# sprit 3

## Wat ga ik doen?

De volgende periode ga ik verder met de menukaart van mijn
restaurantwebsite.

Ik wil hierbij meer JavaScript gaan gebruiken in combinatie met React.

## Taken

Ik wil de volgende taken uitvoeren:

- De Menu-pagina verder uitwerken.
- Een lijst met gerechten maken in JavaScript.
- Leren werken met arrays.
- De gerechten met `.map()` weergeven in React.
- Voor ieder gerecht een naam, beschrijving en prijs tonen.
- De menukaart stylen met CSS.
- De menukaart responsive maken.
- De pagina testen op verschillende schermformaten.

Als er genoeg tijd over is, begin ik daarna met de reserveringspagina.

## Wat wil ik leren?

Tijdens deze periode wil ik leren:

- hoe arrays werken in JavaScript;
- hoe ik gegevens kan opslaan in JavaScript;
- hoe `.map()` werkt;
- hoe React gegevens uit JavaScript op het scherm kan tonen;
- hoe ik herhalende onderdelen kan maken zonder dezelfde JSX steeds
  opnieuw te schrijven;
- hoe ik een pagina responsive kan maken.

## Doel

Aan het einde van deze periode wil ik een werkende en gestylde menukaart
hebben.

De gerechten moeten vanuit JavaScript-data op de pagina worden weergegeven.
Ik wil zelf kunnen uitleggen hoe de JavaScript-code en React-code samenwerken.
